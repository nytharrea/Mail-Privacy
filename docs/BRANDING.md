# Mailx Android visual identity

The application name and Android package identity remain unchanged. This document defines the visual direction only.

## Direction

- Character: dark, restrained, privacy-focused.
- Symbol: geometric spider web with a small envelope at its center.
- Slogan: **Your inbox. Your privacy.**
- Primary accent: teal; avoid mixing unrelated indigo, violet and electric-blue brand accents.
- Surfaces: obsidian and graphite, with a low-contrast border hierarchy.

## Palette

| Token | Hex | Use |
|---|---|---|
| Obsidian | `#0B1118` | Main dark background |
| Graphite | `#151F28` | Elevated surfaces |
| Deep Teal | `#123B3A` | Brand containers |
| Mailx Teal | `#42D6BE` | Primary dark-mode accent |
| Deep Teal Light | `#0F766E` | Primary light-mode action |
| Silver Mist | `#AAB9C0` | Secondary text |
| Frost | `#F1F5F9` | Primary light text |

## Assets

- Source artwork: `assets/branding/mailx-web-mark.svg`
- Android adaptive launcher icon: `android-app/app/src/main/res/mipmap-anydpi-v26/`
- Android vector mark: `android-app/app/src/main/res/drawable/ic_mailx_web_mark.xml`

Keep the logo legible at small sizes. Avoid realistic spiders, gradients that reduce contrast, tiny web strands, or text inside the launcher icon. Status colors (success, warning, error) remain semantic and must not be replaced with brand teal.
