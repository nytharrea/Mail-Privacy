# CI fix — logs 120363173471 / 120363173448

## Actual failure

Both Android Debug and Android Release jobs exited during SDK license acceptance.
The log contains:

`yes: standard output: Broken pipe`

The workflow used `yes | sdkmanager --licenses` under `set -o pipefail`.
`sdkmanager` closes stdin after consuming the license confirmations; `yes` then
receives SIGPIPE, and `pipefail` turns that expected producer shutdown into a
failed step. The Android 37 installation command was never reached.

## Fix

Both workflows now feed confirmations through process substitution:

`sdkmanager --licenses < <(yes 2>/dev/null)`

This removes the producer from the pipeline status calculation while preserving
strict failure handling for sdkmanager itself. API 37 installation and the
android-37 directory/android.jar verification remain enabled.
