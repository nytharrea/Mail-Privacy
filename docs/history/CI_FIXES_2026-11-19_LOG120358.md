declarations in `MailxCoreError` and its variants. `message` clashes with the
message property inherited from Kotlin's Throwable hierarchy. Renamed exported
error payload fields to `detail` in `MailxCoreError` and `SecureStorePortError`,
including every construction site.

workflow SDK installation steps to API 37. `targetSdk` remains 36 to avoid
opting users into new runtime behavior in this build-only change. The emulator
smoke test remains API 36.
