## Android Debug and Release

`Unresolved reference 'jna'`. UniFFI's Kotlin backend uses JNA to call the
native library. Added the Android AAR dependency
`net.java.dev.jna:jna:5.19.1@aar` and an explicit coroutines-core dependency.
Added R8 keep rules for JNA because generated bindings access it reflectively.
